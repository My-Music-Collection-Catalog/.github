## How My Music Collection Sits

My Music Collection does not replace the player, the ripper, or the CDs you already own. It sits beside them as a named music desk for one job: which album catalog is live, which track list still matches the cover shelf, and what the next person should read before the next rip.

If two people share a music PC, each keeps a My Music Collection style of their own. Extra boxes wait for their own title instead of crowding the live cover shelf.

A first visit should be one short album pass, then the same My Music Collection music desk the next day. That is enough to see if the catalog holds.

## Traffic Light

| Signal | On the My Music Collection board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live album list | Continue the same cover shelf |
| Amber | Two boxes mixed in one track list | Split the set before you rip |
| Red | No title, no note, covers missing | Stop and name the desk first |
| Clear | Handoff written, live albums few | Close My Music Collection and leave the desk |

## Open Order

1. Open the last My Music Collection music desk, not a new empty album catalog.
2. Read the track list and the last handoff.
3. Finish one visible cover shelf pass inside My Music Collection.
4. Write what changed, then close with fewer untitled albums than you found.
5. If the set feels crowded, drop anything that belongs to a different My Music Collection box.
6. Confirm My Music Collection still shows covers for the albums you ripped.

## After a Week

A week in My Music Collection is not a larger untitled album pile. It is the same title, a shorter live track list, and a note that still makes sense before the next rip. Take finished albums off the live set so the next visit starts on the catalog that is still open.

Other programs stay where they are. My Music Collection only keeps the path back: desk name, album catalog, cover shelf, handoff.

## Sign-off

- [ ] The My Music Collection workspace name is short enough to scan
- [ ] Only live albums sit on the desk
- [ ] A second person can read the album handoff
- [ ] The last My Music Collection catalog still opens after a restart
- [ ] Finished albums are off the live My Music Collection set

## Field Note

My Music Collection is easier to trust when the music desk stays smaller than the rip folder it came from. Name the catalog, keep the live track list, finish one visible cover pass, and write what changed.

The same loop fits a CD box, a file library, or a shared computer. Open the last My Music Collection desk and continue. Do not rebuild the shelf from scratch.
